# macOS 1.4 (115): synchronize Viewer and Host input modes

## Fix

- The Mac Viewer now switches its own Chinese/English input source when the
  Magic Keyboard 中/英 (Caps Lock position) key is pressed, then sends the
  selected language explicitly to the Host. The Intel Mac no longer needs its
  Caps Lock key configured as an input-source shortcut.
- Control-Space now cycles the Viewer locally and explicitly selects the same
  language on the Host, so subsequent composed text uses the matching mode.
- If macOS cannot select an input source, the Viewer beeps and does not send a
  relative toggle that could desynchronize the two Macs.
