# macOS 1.4 (116): Restore Viewer LAN discovery after Forget/Retry

## Fix

- Forgetting saved Macs or refreshing discovery now clears the old selected
  route, direct-IP hints, and discovery caches.
- A cached private IP no longer counts as an active connection candidate when
  there is no selected Mac or explicit code-first pairing attempt. This keeps
  the idle Bonjour refresh active after Forget All.
- Forget All restarts discovery and newly found Macs remain unpaired until the
  user explicitly selects and connects to one.
