# macOS 1.4 (114): Viewer IME and keyboard input-mode switching

## Fix

- Mac Viewer now uses the local macOS text input system for composition and
  sends committed text to the remote Mac, instead of forwarding uncomposed
  keystroke characters.
- Marked composition is displayed over the remote stream near the pointer,
  and the input-method candidate window is anchored to that location.
- The Magic Keyboard 中/英 key (Caps Lock HID usage 57) toggles the remote
  Mac's Chinese/English input source. Control-Space cycles its input sources.
