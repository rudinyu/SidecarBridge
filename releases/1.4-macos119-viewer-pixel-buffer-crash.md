# macOS 1.4 (119): prevent Viewer crash while tracking decoded frames

## Fix

- Downsample displayed video through Core Image into a bounded, owned pixel buffer before calculating the content fingerprint. This avoids directly indexing decoder-owned pixel memory.
- Give the Debug Viewer a separate bundle identifier and ad-hoc sign UI-test bundles, keeping local test builds distinct from the Developer ID release app.

## Verification

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer bash .codex/ci.sh` passed 242 Host tests, 4 Viewer UI tests, and both macOS Release builds.
- Both Release apps report version `1.4` / build `119` and contain `arm64` and `x86_64` architectures.
- Added coverage that checks content fingerprints for synthetic NV12 video buffers.
